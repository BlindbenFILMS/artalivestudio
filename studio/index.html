    Drag a block to change when it starts, or select it and use the arrow keys. Orange blocks are layers; blue blocks are your narration lines. Press Play as a story to watch it run.

    Scenes over timeblends from one to the next

      A scene is a look: colour mood, atmosphere, weather, sound and how much movement. Set the painting up the way you want, then add it as a scene. Add a few, and the painting changes from one to the next.

      Narrationaudio description in time

        Short lines that are spoken and shown as captions at their time (in seconds), so the description plays along with the animation.

        Tactile versionto feel with your hands

        Turn the painting into something to touch. Print the raised-line drawing on swell paper (capsule paper) and run it through a fuser, or send it to a braille embosser. Use the relief height map to 3D-print the painting as a raised relief, or to cut it on a CNC machine.
